# Explain code skill
1. If a workspace path is given, read it with fs_read; otherwise use the code pasted by the user.
2. First give a 2-sentence summary of what the code does.
3. Then walk through it in logical blocks (not literally every line), explaining intent, not syntax.
4. Finish with 3 things a reviewer might flag.
