Web LLM Harness Connector

1. Harness page

Only pages served from these origins may use the extension. Enter the address you open the harness at (e.g. https://intranet.example.com). Pages opened from a file have the origin file://; add that only if you must, and enable "Allow access to file URLs" in the extension details.

    2. APIs it may call

    The harness may call REST APIs on these origins through the extension, using your browser login (cookies) or a token the harness sends.

      Origins are scheme + host (+ port).
